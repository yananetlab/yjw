# 严珺文的办公作品集

在线访问：[yananetlab.github.io/yjw](https://yananetlab.github.io/yjw/)

四个作品均可用手机浏览，无需安装依赖：

- 考勤表：根据原始Excel的逻辑制作交互演示，支持试选年月、考勤状态及分类统计，并可下载原始文件。
- 公众号：展示两篇已发布图文的实际排版，附微信原文链接。
- 汇报：8页网页版年度小结，支持翻页、连续阅读和打印；数据与事项均为模拟。
- 文档小工具：填写会议纪要或通知，实时预览并导出可编辑的.docx文件。草稿存储在浏览器本机。

## 本地修改

直接打开index.html即可预览。HTML文件中的样式、脚本和预览图均已内嵌，不需要构建工具。

修改并推送到main分支后，GitHub Actions会自动部署。仓库Settings→Pages中的Source应选择GitHub Actions。

发布流程只上传index.html、四个作品页面和Excel文件。简历原文、需求文档与旧版简历页面未放入本仓库。
